# Production dependencies for the Vercel-deployed function only.
#
# This is a deliberately trimmed subset of pyproject.toml's dependencies —
# see docs/decisions/0013-fundamentals-api-vercel-hosting.md. Excluded on
# purpose because nothing on the live request path imports them:
#   - polars (declared, never actually imported anywhere)
#   - camelot-py / opencv-python-headless (PDF *table* extraction — only
#     app/ingestion/pdf_financials.py uses them, and app/main.py never
#     imports that module; camelot also needs a system Ghostscript)
#   - alembic — migrations are run out-of-band against the production
#     database, not from the deployed function itself.
#
# pdfplumber IS included: app/ingestion/pdf_text.py (plain-text extraction
# for the Phase 10 corpus indexer, POST /documents/extract-text) is on a
# live route. It is pure Python (pdfminer.six + Pillow), no system deps. It
# is still imported lazily inside that module so trimming it degrades to a
# 422, not an app-startup crash.
#
# Tier 3 (app/ingestion/tier3_screener_scrapling/scraper.py) fetches via
# httpx and parses with scrapling.parser.Selector directly — NOT
# scrapling.fetchers.Fetcher, whose import chain pulls in Playwright's
# ~130MB bundled Node driver even for the plain curl_cffi-based static
# fetcher (scrapling.engines.toolbelt.convertor imports playwright
# unconditionally at module load, just for an exception type). Selector is
# the same parsing engine with no such import chain. So neither scrapling's
# [fetchers] extra nor curl_cffi is needed here at all.
#
# Local dev / tests still use pyproject.toml's full dependency set via
# `pip install -e ".[dev]"` — this file only affects what Vercel installs.
