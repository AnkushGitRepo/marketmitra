# Session Log

Rolling log of work sessions. Append new entries at the **bottom** (oldest first, newest last) and read the **last 3 entries** to catch up. This file holds only the newest ~12 entries so it can be read whole. When it passes 15 entries, move the oldest, unedited, into the monthly archive until 12 remain (see the context maintenance protocol in `AGENTS.md` and [ADR 0063](./decisions/0063-session-log-archive-by-month.md)). Never rewrite history, and never summarise an entry on the way.

> **Older entries are not lost.** Every entry older than the ones below is in [`docs/archive/session-log/`](./archive/session-log/README.md), one file per month, as it was written. Search it with grep instead of reading it (the README there has the commands). The Phase 0–10 build history is in the compressed [`session-log-archive.md`](./archive/session-log-archive.md) (Rollup 1 = Phases 0–7, Rollup 2 = Phase 8 + Phase 9, Rollup 3 = Phase 9 follow-ups + Phase 10). Per-feature build detail: [`/docs/archive/`](./archive/).

## 2026-11-20 — Mitra Fund X-Ray on the fund page (#274)

## 2026-11-20 — Compare page: summary, growth chart, add and swap, portfolio fit, groups (#280)
